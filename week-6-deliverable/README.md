# Iroo Motors JavaScript Webpage Assignment

## Project Title
Application of JavaScript on a Predefined Webpage

## Project Description
This project is a fictional luxury car dealership webpage called **Iroo Motors**. The webpage demonstrates how JavaScript can be applied to a predefined webpage.

## Files Included
- `index.html` - The main webpage structure
- `styles.css` - The styling and responsive layout
- `script.js` - JavaScript functionality
- `assets/` - Local vehicle illustrations used on the webpage

## Learning Outcomes Demonstrated
1. **Document Object Model (DOM)** - JavaScript reads and changes page elements without reloading the page.
2. **DOM Selectors** - `getElementById()`, `querySelector()`, and `querySelectorAll()` select real page elements.
3. **DOM Events** - `addEventListener()` handles `click`, `input`, `change`, `submit`, `mouseover`, and `mouseout`.
4. **Callback Functions** - `map()`, `filter()`, `forEach()`, and `setTimeout()` are used across the features.

## JavaScript Features Used
1. Current date and time display
2. Light and dark mode toggle (saved in localStorage)
3. Mobile navigation menu
4. Animated statistics counters
5. Vehicle search (by brand or model)
6. Vehicle filtering by brand, price, and vehicle type
7. Dynamic vehicle cards rendered from a JavaScript array of objects
8. Vehicle details modal (brand, model, year, price, mileage, transmission, fuel, type)
9. Favourites feature with live counter and saved-vehicle list
10. Hover interactions on vehicle cards (mouseover / mouseout)
11. Booking form validation
12. Vehicle enquiry form validation (name, email, phone, vehicle, message)
13. Price display using the select menu
14. LocalStorage for saving theme and latest booking reference

## How to Open
1. Download and unzip the project folder.
2. Open the folder.
3. Double-click `index.html` to view the webpage in a browser.

## How to Submit
Submit the full folder or the zip file. Make sure `index.html`, `styles.css`, `script.js`, and the `assets` folder are all included together.
