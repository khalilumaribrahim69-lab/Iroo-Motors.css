Learning Outcome

JavaScript applied on this webpage

The webpage demonstrates practical JavaScript features below.

1. DOM Selectors

getElementById, querySelector, and querySelectorAll select real page elements used for every feature.

2. DOM Manipulation

textContent, innerHTML, classList, and style update prices, counters, cards, and messages without reloading.

3. DOM Events

click, input, change, submit, and mouseover listeners power search, favourites, modal, and forms.

4. Callback Functions

filter, map, forEach, and setTimeout are used to process the vehicle data and update the page.

5. Vehicle Search & Filter

Search by brand or model and filter by brand, price, and vehicle type.

6. Favourites & Details

Save favourite vehicles and view full specifications in a details modal.
